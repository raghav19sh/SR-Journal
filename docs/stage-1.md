# Stage 1 — Local-first foundation

## Implemented
- Expo/React Native foundation
- Expo Router navigation
- Monthly calendar
- Local SQLite journal metadata
- Local device video storage
- Camera + microphone recording
- Entry playback
- Day view
- Delete entry + local video
- Android/iOS identifiers
- No account, cloud upload, analytics, or advertising

## Security boundary
This is not yet the final production security layer. Stage 2 must add encrypted local storage/key management, biometric app lock, secure identifiers, platform backup policy, threat modeling, and security testing.

Do not market Stage 1 as end-to-end encrypted until those controls are implemented and tested.
